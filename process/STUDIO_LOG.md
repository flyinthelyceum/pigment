# Studio log

What was seen, newest last. `BENCH_LOG.md` records whether the instrument works.
This file records what happens when someone looks: the evidence for the inquiry in
`docs/INQUIRY.md`.

Write an entry whenever the eye and the instrument were in the same place: a
session in the chamber, a class run, a light that felt wrong. This is a studio
notebook, not a lab notebook. Write what it was like before you look at the
trace, and let neither correct the other. Memory belongs here too: what stayed
with you the next day is as much the record as what you saw at the time.

```
## YYYY-MM-DD — piece or test
Commit: <sha, or "none" if nothing ran>
Setup: what was lit, how dark, how long you'd been in it
Felt: in your own words, before looking at the trace
Instrument said: the reading, or a photo of the trace
Others: anyone else who was there, in their own words
Remembered: added later, what stayed
Next: what this changes
```

Photos and traces go in `process/studio/YYYY-MM-DD/`, named in the entry.
